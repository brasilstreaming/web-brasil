# Hello, World! 👋

Site estático responsivo feito com HTML, CSS e JavaScript.

## Como abrir

Abra `index.html` no navegador.

## Publicação no GitHub

Este projeto está na pasta `hello-github/` do repositório público
[brasilstreaming/web-brasil](https://github.com/brasilstreaming/web-brasil).

## Publicar usando GitHub Pages

Nas configurações do repositório, abra **Settings → Pages** e selecione
**Deploy from a branch**, branch **main** e pasta **/(root)**.

Com Pages ativo nessa configuração, a página deste subdiretório poderá
ser acessada em:
https://brasilstreaming.github.io/web-brasil/hello-github/

> A URL acima só funciona depois da ativação bem-sucedida do GitHub Pages.

## Arquivos

- `index.html`: estrutura
- `styles.css`: estilos responsivos
- `script.js`: interação do botão
